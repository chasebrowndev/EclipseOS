### Notes
- foot and alacritty have no kitty graphics; that gap is what Apotheosis fills, so no row.

### Open questions
- Kitty a=f frame storage: eager full-size RGBA (chosen) could exceed quota fast for long GIFs; need a decision on spilling frames to disk or compressing.
- Can wgpu export textures as dmabuf for handing buffers to Abyss? Not found (unverified).
- Whether iTerm2 inline images are wanted at should or could; one source marked protocol details unverified.
- Text sizing (OSC 66) grid layout rules need a design before commit.
- Exact default quota: kitty 320 MB vs rio 400 MiB decoded cap; we use 320 MB with a 400 MiB per-image ceiling.
- No ratified terminal-wg image protocol found; issue search failed.
