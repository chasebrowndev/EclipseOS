## Open questions

- Should the nightly/dev channel be a separate `-git` PKGBUILD or a repo-side pre-release channel? Rows give no evidence.
- Terminfo naming: one entry vs. a separate direct-colour entry, and whether to also claim compatibility with `TERM=foot*` consumers (unverified how much software keys on it).
- Should the daemon be the default mode (like foot server) or optional? Rows only cover socket activation mechanics.
- Whether the version query should be an Action in the shared vocabulary or only a CLI/socket method.
