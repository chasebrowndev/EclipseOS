### Open questions

- AccessKit's unix adapter maturity: does it support the full AT-SPI text interface (offsets, granularity, attributes, extents, hyperlinks) needed for 01, 05-08, 14, or must we extend it or contribute upstream? Verify before committing.
- Does AccessKit expose a text-run model that can accept our snapshot/diff events (02) without rebuilding whole subtrees, and how does it handle per-pane update rate?
- Threading: AccessKit/zbus run on their own executor; confirm snapshot hand-off from the render thread is lock-free enough for the hot-path rule.
- Screen-reader testing matrix (Orca, plus magnifier on Abyss) is undefined; Orca behaviour with terminal role text on Wayland is unverified.
- Does Abyss need an accessibility-relevant protocol for AT focus/caret reporting (magnifier tracking), or does AT-SPI suffice on Wayland?
- ACCESSIBILITY-13 default verbosity values are our design, not prior art; need user testing.
- Rendering minimum-contrast (17) against a blurred translucent background: which effective bg sample to use (theme bg, measured blur luminance)? Unresolved.
- Whether unicode-input (19) should ship given text-input-v3 and compose-key coverage.
