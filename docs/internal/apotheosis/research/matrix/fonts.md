## fonts

| ID | Feature | Mechanism we adopt | Control surface | Adopt | Seen in | Rationale |
|---|---|---|---|---|---|---|
| FONTS-01 | Procedural box, block, braille, Powerline and legacy-computing glyphs | Cells in U+2500-259F, braille, Powerline (U+E0B0 range) and Symbols for Legacy Computing (sextants, octants, etc.) are drawn by our code, not taken from fonts. Each sprite is rasterized once on the CPU to an exact-cell coverage bitmap (anti-aliased, thickness derived from cell size/DPI) and uploaded to the atlas like any glyph. One range check rejects non-sprites. | KDL `font { builtin-glyphs { enabled; ranges; box-thickness; solid-shades } }`; GUI toggle per range group | must | kitty, ghostty, foot, alacritty, rio, windows-terminal, notcurses | Six terminals do it. Pixel-exact joins at any cell size and fractional scale, no fallback-font dependence, and blitter output (octants/sextants) looks right. CPU-raster-to-atlas (rio/ghostty) is chosen over WT's packed instruction table and over shader drawing: it is simplest, shares the atlas path, and needs no per-frame cost. Cursor and underline-style sprites use the same path. |
| FONTS-02 | Font stack: per-style families, ordered fallback, per-attribute rules | `font` node has family plus ordered `fallback` list; separate stacks for regular/bold/italic/bold-italic; rules may select a stack by attribute (bold/italic/intensity). User list searched first, then system fallback (FONTS-17). | KDL `font { family; fallback; rule { bold; italic } }`; actions to change font at runtime; GUI font page | must | wezterm, foot, ghostty, kitty | Every mature terminal exposes it; fontconfig's own monospace fallback is poor, so user order must win. |
| FONTS-03 | Codepoint-range font map and symbol map | Ranges (U+XXXX-YYYY) map to a named font, overriding the stack; checked before normal fallback. | KDL `font { symbol-map "U+E000-F8FF" font="..." }` | must | kitty, ghostty, rio | Core control for icon fonts; three terminals ship it. |
| FONTS-04 | Per-font OpenType feature strings | Parse `+ss01 -calt liga=0` style lists per family/style and pass to shaper as feature overrides; applied per stack entry. | KDL `font { features "+ss01" "-calt" }`; GUI chips | must | kitty, wezterm, ghostty, foot, rio, topic-fonts | Core control for coding fonts. |
| FONTS-05 | Variable font instances and variation axes | Per-style variation settings (e.g. wght, slnt) applied both to the shaper instance and to the skrifa outline location; named instances selectable. | KDL `font { variation { wght 450 } }` per style; GUI sliders from the font's axes | must | ghostty, kitty | Required for variable families and weight tuning. |
| FONTS-06 | Integer cell metrics with explicit rounding and adjustments | Cell width = rounded advance, height = rounded line height (round, not ceil); line gap split half above/half below; baseline derived from cell bottom; every metric minimum 1 px. User adjustments (cell width/height, baseline, underline/strike/overline/cursor position and thickness) applied after, in px or percent. | KDL `font { adjust { cell-width; cell-height; baseline; underline-position; underline-thickness; strikethrough-*; overline-*; cursor-* } }` | must | ghostty, kitty (modify_font), foot | DPI-stable layout, no zero-thickness lines; the control surface is expected by users. |
| FONTS-07 | Cell-width overrides for codepoint ranges | Table maps ranges to 1 or 2 cells (or forced narrow) for the wcwidth layer and the renderer, so PUA icons and ambiguous symbols agree between app and terminal. | KDL `font { cell-width "U+E000-F8FF" 1 }` | should | kitty (narrow_symbols), wezterm (cell_widths) | Two terminals; fixes Nerd Font width disputes. Must be consistent with the grid's own width table, so it lives in the shared width layer. |
| FONTS-08 | Nerd Font constraints, cap-height fallback scaling, optional embedded symbols font | Generated per-codepoint table (scale, alignment, constrain-to-cell) for PUA icons, applied when the glyph comes from a symbols/fallback font; fallback fonts optionally scaled to match primary cap height. Optionally ship a symbols-only Nerd Font so icons work unpatched. | KDL `font { icon-height; scale-fallback-to-cap-height; embedded-symbols }` | should | ghostty, rio, kitty, wezterm | Icons are not fixed width; avoids clipping/overlap and patched fonts. Table derived from the ghostty-style generated approach (regenerate, do not copy). Embedded font needs a licence check (open question). |
| FONTS-09 | Shaping engine: harfrust on skrifa | Shape with harfrust (MIT, pure Rust, ShapePlan cached per font/script/language/features); shapes in font units, we scale advances. Parser family is skrifa/read-fonts only (FONTS-24). | none (internal); `font { shaping { enabled; ligatures } }` | must | topic-fonts, wezterm (HarfBuzz), kitty, ghostty | No C allowed; harfrust is maintained and supersedes rustybuzz. |
| FONTS-10 | Run shaping in the grid with cell-aligned ligatures | Shape per line in style/font runs; map each shaped cluster back to grid cells; ligature glyphs and multi-cell clusters occupy their cells exactly. Per-grapheme-only rendering is not accepted for the grid; text-run shaping also used for glass UI text. | KDL `font { shaping { ligatures true } }`, action `toggle-ligatures` | must | wezterm, kitty, ghostty, windows-terminal | foot's grapheme-only grid is a known gap users complain about. |
| FONTS-11 | Shaped-run cache | Single-threaded cache keyed by text+style+font+features; lookups use a borrowed key (no allocation on hit). Layout: bucketed N-way associative table (rio: 256x8, move-to-end LRU inside bucket), values shared (Rc/Arc) shaped glyph arrays; bounded memory. | none; `font { shape-cache-size }` advanced | must | wezterm, rio | Allocation-free hits are the core of fast shaping and fit our single-thread render loop. Combine wezterm's borrowed key with rio's bounded bucket design. |
| FONTS-12 | Simple-text fast path | Classify runs that need no shaping (ASCII/simple scripts, no features that change them, no ligature font) and emit one glyph per cell using the cell advance; skipped when features are set. | none | must | windows-terminal | Large CPU saving on ASCII-heavy output. |
| FONTS-13 | Ligature policy: break under cursor | Split shaping runs at the cursor cell (and optionally selection) so ligatures un-ligate there for editing; policy configurable. | KDL `font { shaping { break-at cursor|never } }`, `disable-ligatures never|cursor|always` | should | kitty, ghostty | Two terminals; small usability win. |
| FONTS-14 | Ligature overlap split for per-cell colour | Glyphs overhanging more than half a cell are sliced into cell-wide chunks so each cell takes its own foreground/background. | none | should | windows-terminal | Correct colours in coloured ligatures; also needed for wide glyph selection/cursor rendering. |
| FONTS-15 | Font discovery: fontdb scan plus fontconfig-parser | Pure-Rust directory scan with CSS-like family/weight/stretch/style query; honour fontconfig config via the pure-Rust parser only, no libfontconfig; extra font directories configurable. | KDL `font { directories; }` | must | topic-fonts, rio | Satisfies the no-C and allowed-library rules. fontdb lacks codepoint queries, hence FONTS-16. |
| FONTS-16 | Per-face charmap coverage index | Cache each face's charmap as sorted codepoint ranges (on disk, invalidated by mtime) so fallback lookup is a binary search without opening fonts. | `apotheosis-ctl font query U+XXXX` | must | topic-fonts (own design), rio (fontconfig charset sort equivalent) | Needed for lazy per-codepoint system fallback and for diagnostics. |
| FONTS-17 | Fallback resolution with grapheme-common font | For a cluster, collect supporting fonts per codepoint and choose one font covering all (ZWJ, keycap, VS sequences); order: user list, symbol map, then system coverage index; merge adjacent runs resolved to the same face. Missing glyph cached once. | via FONTS-02 | must | ghostty, windows-terminal, kitty | Prevents sequences splitting across fonts; merging avoids per-run overhead. |
| FONTS-18 | Colour emoji: COLRv0/v1, CBDT/sbix | Own COLRv1 painter on skrifa's ColorPainter (solid/linear/radial/sweep gradients, clips, composite modes) into RGBA, cached per (glyph,size) in a separate colour atlas; swash/skrifa for COLRv0, sbix and CBDT bitmaps. Emoji vs text presentation decided from VS15/VS16, default presentation and font coverage. | `font { emoji { presentation; font } }` | must | wezterm, rio, topic-fonts | Modern emoji (Noto COLRv1) require it; swash alone lacks COLRv1. |
| FONTS-19 | CPAL light/dark palette selection | Choose CPAL palette by background luminance when the font offers one. | `font { emoji { palette auto|light|dark } }` | could | topic-fonts | Cheap polish following theme. |
| FONTS-20 | Hinting and rasterization options | skrifa HintingInstance: none, light (vertical-only auto-hinter, default) and full (interpreter); grayscale AA, optional subpixel only when compositor/output layout is known; fractional glyph offsets. | `font { hinting none|light|full; antialias }` | must | topic-fonts, foot, kitty | Light hinting is the usual default; users expect the knob. |
| FONTS-21 | Synthetic bold and italic | When a style is missing, embolden by outline offset and skew for italic; thickness adjustable; toggle. | `font { synthetic-style bold italic; thicken }` | should | ghostty, rio, kitty | Fonts without styles are common. |
| FONTS-22 | Glyph atlas keyed by shaped glyph id | Key = (font id, glyph id, variation/style, size bucket quantized to 1/4 physical px); multi-page shelf-packed atlases (mono R8 and colour RGBA separate), bounded pages with eviction. Never key by char. | none | should | rio | Resize and fractional-scale reuse with bounded memory. Keying on glyph id is mandatory (see FONTS-26). |
| FONTS-23 | Preload ASCII per style | Rasterize printable ASCII for each style at load and on size change. | none | could | alacritty | Avoids first-frame hitches; cheap. |
| FONTS-24 | Single parser family; swash only for UI text and bitmaps | skrifa/read-fonts for outlines, metrics, hinting, colour; swash (also on skrifa) permitted for glass UI text masks and bitmap emoji; grid sprites and COLRv1 use our own path. | none | must | topic-fonts, rio | One safe (forbid unsafe) parser for shaping and raster, dual MIT/Apache. |
| FONTS-25 | Bidi and complex-script shaping with a real shaper | Shape Arabic and other joining scripts per paragraph run with harfrust, not presentation-form substitution; covers glass UI text and, where the grid supports bidi, grid rows. | `font { shaping { enabled } }` | should | vte-konsole (limitation noted) | Avoid VTE's known presentation-forms limitation. Grid bidi scope is outside this category. |
| FONTS-26 | Rejected: char-keyed glyph cache, FreeType/fontconfig FFI, rustybuzz/ttf-parser, cosmic-text for grid, OT-SVG, grapheme-only grid | Not adopted: char-keyed cache (blocks ligatures/clusters), crossfont/FreeType/fontconfig FFI (C), rustybuzz and ttf-parser (stale, second parser family), cosmic-text as grid engine (no exact cell placement), SVG-in-OpenType (large scope, low payoff), grapheme-only grid shaping. | n/a | no | alacritty, foot, topic-fonts | Each conflicts with a fixed decision or loses to a chosen alternative above. fontique (could, FONTS-27) is the one borderline case. |
| FONTS-27 | fontique for UI-text fallback | Possible source of generic-family and script/locale fallback for glass UI text only; must be configured without fontconfig dlopen. | none | could | topic-fonts | Unverified feature set; evaluate against FONTS-15/16 first. |
| FONTS-28 | Font diagnostics CLI and GUI chooser | CLI `ls-fonts` prints the resolved chain with per-glyph source, features, metrics, and which rule matched; GUI chooser previews families, styles, named instances and variation axes live and writes the same KDL. | `apotheosis-ctl font list|query|resolve`; Settings > Fonts | should | wezterm, kitty | Debuggability; chooser is the settings-GUI face of FONTS-02..05. |
| FONTS-29 | Glyph Protocol (APC 25a1) | Apps query coverage and register runtime glyphs as glyf/COLRv0/COLRv1 payloads (verbs s/q/r/c); registered glyphs go to a PUA-like sprite space in the atlas; unsupported terminals ignore the APC. | `font { glyph-protocol enabled }` | could | ghostty | Removes patched-font need; experimental, track upstream; payloads are untrusted input so parsing must be sandboxed/limited. |
| FONTS-30 | Font size and cell scale limits | Clamp font scale 0.25-4.0 and line/letter spacing scale 1.0-2.0; actions zoom-in/out/reset and wheel zoom. | `font { size; cell-scale }`, actions `font-zoom-in|out|reset` | could | vte-konsole, konsole | Sensible bounds; zoom actions are expected anyway. |

### Open questions

- Embedded symbols-only Nerd Font: licence and size acceptable (OFL fonts vs allowed list)? Needs a decision before FONTS-08 ships it.
- Whether fontique can be built without any fontconfig dlopen (FONTS-27); unverified.
- Subpixel (LCD) antialiasing: needs compositor output-layout info; Abyss integration only? Not settled by rows.
- Grid bidi scope (FONTS-25) belongs to the terminal-core category; confirm the boundary.
- Size/shape of the coverage-index on-disk cache and invalidation (FONTS-16).
- harfrust maturity versus HarfBuzz for rarer scripts (unverified).
- Whether octant/sextant sprite set follows Unicode 16 exactly, and if the legacy-computing range list is user-trimmable.
