# 0110 — Apotheosis language rule and system-library allow-list
Status: accepted
Date: 2026-11-12
Deciders: chase (owner), Claude (advisory)

## Context
The owner's rule: everything we write is Rust, configuration is KDL. The research phase found where the rule meets reality: Vulkan WSI needs the real `libwayland-client`; hardware video needs `libva`; many convenient crates compile C in a build script or run bindgen; `rustc` itself drives the system linker.

## Options
1. "Pure Rust, no exceptions": no hardware video, no Vulkan surface on Wayland. Not viable.
2. "Rust where convenient": the rule decays one build script at a time.
3. A precise, mechanically enforced rule: our source is Rust; no C-family source is compiled by our build or any dependency's build script; no build-time bindgen; a closed allow-list of system libraries; exceptions only by ADR.

## Decision
Option 3, as written in T-00 §3.1–§3.3. Allow-list: glibc/libgcc_s, `libwayland-client`, the Vulkan loader and driver, `libxkbcommon` (optional feature only), `libva` and `libva-drm` (helper only, loaded at run time). PipeWire is **not** on the list: audio is a pure-Rust PulseAudio-protocol client. Bindings are generated by a dev-only xtask and committed. Shell-integration snippets, WGSL and generated terminfo text are data assets. Two standing exceptions: `nasm` for `rav1d` at build time (ADR 0118), and the non-shipping `apotheosis/fuzz/` workspace (cargo-fuzz + libfuzzer-sys C++ runtime, own pinned nightly), skipped entirely by `lang-rule.sh`.

## Consequences
`apotheosis/ci/lang-rule.sh` (T-24 §3) fails the gate on a C-family file, a build script that invokes `cc`/`cmake`/`bindgen` outside the reviewed list, or a linked library outside the allow-list. Rejected on these grounds: `pipewire-rs`, in-process ssh libraries, C-backed codec crates, the gles backend of wgpu, `gbm`. Vendored forks of `cros-libva`/`cros-codecs` carry the cost of the rule. No shipping crate may depend on the fuzz workspace, asserted in T-24 §3.

## Revisit when
A needed capability has no pure-Rust or allow-listed path, or an allow-listed library gains a maintained pure-Rust replacement (then the list shrinks).
